
# Environment Separation Plan: TEST vs LIVE

## Executive Summary

This plan transforms the current "runtime switching" architecture (where a single deployment decides Stripe mode per-record) into a clean "environment-determines-everything" model where:
- **TEST deployment** → Stripe Sandbox → TQ-prefixed quotes → test data only
- **LIVE deployment** → Stripe Live → Q-prefixed quotes → production data only

---

## Current State Analysis

### What Exists Today

**Stripe Key Switching (13 edge functions)**
- Functions like `create-stripe-quote`, `cancel-quote`, `check-subscription` contain `getStripeKey(isTest)` logic
- They read `is_test` from database records and conditionally use `STRIPE_SECRET_KEY` vs `STRIPE_SECRET_KEY_LIVE`

**Database `is_test` Flags**
| Table | Purpose |
|-------|---------|
| `customers` | Marks test customers |
| `quotes` | Marks test quotes |
| `invoices` | Marks test invoices |
| `skus` | Marks test SKUs |

**Quote Numbering**
- Single sequence: `Q-00000001`, `Q-00000002`, etc.
- Generated by `generate_quote_number()` trigger
- No environment prefix differentiation

**Secrets Configuration**
- `STRIPE_SECRET_KEY` (sandbox)
- `STRIPE_SECRET_KEY_LIVE` 
- `STRIPE_INVOICE_WEBHOOK_SECRET` (single webhook, not environment-aware)

#### 1.2 Create Shared Stripe Utilities Module

Create `supabase/functions/_shared/stripe-env.ts`:

```typescript
/**
 * Environment-aware Stripe configuration
 * Single source of truth for Stripe API access
 */

export type AppEnvironment = "test" | "live";

/**
 * Get the current environment - fails hard if not configured
 */
export function getAppEnvironment(): AppEnvironment {
  const env = Deno.env.get("APP_ENV");
  if (!env) {
    throw new Error("FATAL: APP_ENV is not set. Deployment is misconfigured.");
  }
  if (env !== "test" && env !== "live") {
    throw new Error(`FATAL: APP_ENV must be 'test' or 'live', got '${env}'`);
  }
  return env as AppEnvironment;
}

/**
 * Get and validate Stripe secret key for current environment
 * Enforces key prefix matches environment (fail-closed)
 */
export function getStripeSecretKey(): string {
  const env = getAppEnvironment();
  const key = Deno.env.get("STRIPE_SECRET_KEY");
  
  if (!key) {
    throw new Error("FATAL: STRIPE_SECRET_KEY is not set");
  }
  
  // CRITICAL: Validate key matches environment
  const isLiveKey = key.startsWith("sk_live_");
  const isTestKey = key.startsWith("sk_test_");
  
  if (env === "live" && !isLiveKey) {
    throw new Error(
      "FATAL: APP_ENV is 'live' but STRIPE_SECRET_KEY is not a live key. " +
      "Refusing to proceed - check secret configuration."
    );
  }
  
  if (env === "test" && !isTestKey) {
    throw new Error(
      "FATAL: APP_ENV is 'test' but STRIPE_SECRET_KEY is not a test key. " +
      "Refusing to proceed - check secret configuration."
    );
  }
  
  return key;
}

/**
 * Check if running in test environment
 */
export function isTestEnvironment(): boolean {
  return getAppEnvironment() === "test";
}

/**
 * Get quote number prefix for current environment
 */
export function getQuotePrefix(): string {
  return isTestEnvironment() ? "TQ-" : "Q-";
}
```

### Phase 2: Quote Numbering Separation

#### 2.1 Modify Quote Number Generator

Update the `generate_quote_number()` database function:

```sql
CREATE OR REPLACE FUNCTION public.generate_quote_number()
RETURNS TRIGGER AS $$
DECLARE
  next_num INTEGER;
  prefix TEXT;
  app_env TEXT;
BEGIN
  -- Get environment from application setting (set per deployment)
  app_env := current_setting('app.environment', true);
  
  -- Determine prefix based on environment
  IF app_env = 'live' THEN
    prefix := 'Q-';
  ELSE
    prefix := 'TQ-';
  END IF;
  
  -- Get the next number for THIS prefix only
  SELECT COALESCE(MAX(
    CASE 
      WHEN quote_number ~ ('^' || prefix || '\d+$') 
      THEN CAST(SUBSTRING(quote_number FROM LENGTH(prefix) + 1) AS INTEGER)
      ELSE 0
    END
  ), 0) + 1
  INTO next_num
  FROM public.quotes
  WHERE quote_number LIKE prefix || '%';
  
  -- Set the quote number with 8-digit padding
  NEW.quote_number := prefix || LPAD(next_num::TEXT, 8, '0');
  
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SET search_path TO 'public';
```

## Risk Mitigation

1. **Fail-Closed Design**: Stripe key validation throws hard errors if environment/key mismatch detected
2. **Gradual Rollout**: Changes deploy to TEST first, thoroughly tested before LIVE publish
3. **Data Backup**: Ensure backups exist before running cleanup scripts
4. **Rollback Plan**: Keep `is_test` columns during transition; old logic can be restored if needed
5. **Quote Number Preservation**: Existing quote numbers remain valid; only new quotes get environment-prefixed numbers
